# Arquivos do MakeHuman

Malha base (`base.obj.gz`), esqueleto padrão (`default.mhskel.gz`, `default_weights.mhw.gz`), os poucos ajustes
(targets) usados pela Vampirinha e os olhos "high-poly" com a textura castanha.

Vêm do repositório do MakeHuman (https://github.com/makehumancommunity/makehuman) e foram liberados como
CC0 1.0 (domínio público) — veja `LICENSE.ASSETS.md`. Os arquivos de texto foram só comprimidos com gzip.
